# Обводка декора шейдером — план

## Решение

Чёткий белый контур (crisp outline) по краю спрайта декора **через UI-шейдер**,
для N предметов **разной формы**. Показывается на выбранном занятом слоте
(клик по `DecorSlotAnchorView` → `ShowHud`).

Почему шейдер, а не запечённый спрайт: контур строится альфа-дилатацией по
силуэту **каждого** спрайта автоматически. Для N разных форм запечённый контур
потребовал бы N ручных ассетов, а один общий не повторит разные силуэты.
(Для мягкого glow вывод был бы обратный — там дешевле запекать; см. историю
обсуждения. Здесь выбран именно чёткий контур.)

## Открытый вопрос (решить ДО написания шейдера)

**Толщина контура должна быть визуально одинаковой на всех N предметах?**

Ширина считается от `_MainTex_TexelSize` (1 / размер текстуры). Если спрайты
разного нативного разрешения — фиксированный шаг в текселях даст **разную
толщину на экране** (на 128px толще, чем на 512px).

- Если **да, ровная** → этап 1 включает нормализацию разрешения/PPU спрайтов.
- Если **«плюс-минус»** → пропустить нормализацию, выставить `_OutlineWidth` на глаз.

## Этапы

### 1. Арт-подготовка (самый трудозатратный этап)
- (Если нужна ровная толщина) привести декор-спрайты к **единому PPU/разрешению**.
- **Прозрачный бордюр** в каждом спрайте (2–4 px под тонкий контур). Иначе
  силуэт у края текстуры срежет даже 1px обводку.
- В импорте спрайтов **Mesh Type = Full Rect** (не Tight — Tight обрежет меш по
  силуэту, и контур исчезнет).

### 2. UI-шейдер
- База — `UI/Default`, **сохранить stencil-блок** (`Stencil { Ref [_Stencil] Comp [_StencilComp] ... }`) — обязательно из-за `Mask`.
- Тело: **8-тап альфа-дилатация** (семплы по кольцу через `_MainTex_TexelSize`),
  вывод белого там, где дилатированная альфа > альфы центра.
- Проперти: `_OutlineColor` (белый), `_OutlineWidth`.
- Без анимации (статичный контур).

### 3. Два общих материала
- `plain` — дефолтный UI-материал (не-выбранные слоты рисуются как обычно).
- `outline` — материал с шейдером из этапа 2.
- **Инстансы не нужны** (контур статичный): один общий `outline` корректно
  работает на всех спрайтах — UGUI подаёт текстуру каждого Image через его
  CanvasRenderer, `_MainTex` у каждого свой. Это убирает per-instance инстансы,
  их lifecycle и утечки.

### 4. Переделка тоггла
- `SetSelectedOutline(true/false)` → свап `_placedDecorImage.material` между
  `outline`/`plain` вместо `SetActive` на `_selectedOutline`.
- `SetEmpty` → вернуть `plain`.
- Поле `_selectedOutline` становится лишним: выпилить либо переиспользовать под
  ссылки на материалы.
- Контроллер (`ShowHud`/`HideHud`) не трогаем.

### 5. Проверки
- Толщина контура ровная на всех предметах (зависит от решения по открытому вопросу).
- Контур не течёт за края под `Mask` (stencil ок).
- Разные Canvas Scale / разрешения — ширина не разъезжается.

## Критические риски (где чаще всего ломается)

1. **Stencil** — в префабе есть `Mask`; шейдер без stencil-ops сломает отсечение.
2. **Прозрачный бордюр** в артах — иначе контур срежет рамкой.
3. **Full Rect** вместо Tight mesh — иначе меш обрежет контур по силуэту.
4. **Ровная толщина на N спрайтах** — texel-зависимость ширины при разном
   разрешении.

Пропуск любого: контур либо обрежется, либо разломает маску, либо будет «гулять»
по толщине.

## Оценка

- Сам шейдер (этап 2) — пара вечеров с отладкой под маской.
- Основная трудозатрата — **этап 1** (ревизия импорта/разрешения всех декор-спрайтов).
- Этап 3–4 упрощены благодаря выбору «чёткий статичный контур»: два общих
  материала + свап, без инстансов.

## Если позже понадобится анимация

Свап двух общих материалов не даёт пер-слотовую анимацию толщины/мигания.
Для анимации придётся вернуться к **инстансу материала** на выбранном Image
(создать/уничтожить в `OnDestroy`, минус батчинг) и твинить `_OutlineWidth`
через DOTween (уже подключён — [DecorSlotAnchorView.cs:2](../../Assets/Game/Features/Decor/UI/DecorSlotAnchorView.cs)).
